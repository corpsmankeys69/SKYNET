# Epic Training Quick Start Guide Template

A Word template (.dotx) for building Quick Start Guides: short, workflow-based how-to documents for Epic training. It belongs to UW Medicine | Fred Hutch. Use it as the style spec whenever a document must match it. (sources/2026-10-06-epic-training-quick-start-guide-template.md)

## Page
- US Letter, 1 in margins on all sides. Header at 0.3 in, footer at 0.19 in. (sources/2026-10-06-epic-training-quick-start-guide-template.md)
- Page 1 is the title block plus an automatic Table of Contents (levels 1 to 3, dot leaders, right tab at 9350). Content starts on page 2. Each main topic starts on a new page.

## Fonts
- Body: Calibri Light, 11 pt, color 00000A (near-black), line spacing 1.2 ([Basic Paragraph] style).
- Headings and theme fonts: Calibri / Calibri Light. No other typeface is used.
- Tip box text: Calibri Light, 11.5 pt, letter spacing +0.3 pt, via the Tip Text character style.
- Hyperlinks: color 0563C1, underlined.

## Colors
- Brand purple 38296B: all headings, the TOC heading, and "Epic Training" in the header. (sources/2026-10-06-epic-training-quick-start-guide-template.md)
- Text black 00000A. Callout borders black, icons black with white glyphs. No shading anywhere.
- Footer bar gradient, left to right: 32006E, 261B65, 1B365D.
- The Word theme is stock Office, so the brand colors live in styles, not in the theme palette. Picking colors from the theme picker gives the wrong colors.

## Heading scale
| Level | Role | Size | Weight | Color |
|---|---|---|---|---|
| Heading 1 | Guide title, "Call Out Boxes" style top sections | 16 pt | Bold | 38296B |
| Heading 2 | Main topic (a workflow) | 14 pt | Regular | 38296B |
| Heading 3 | Subtopic | 12 pt | Regular | 38296B |

## Header (every page)
1. "Epic Training": 16 pt, bold, 38296B, left aligned.
2. "[Title] Quick Start Guide": 12 pt, regular, black.
3. "Application | Audience": 7 pt, black.

## Footer (every page)
- Centered page number (PAGE field).
- Left: version line, format "v1.0 MM.DD.YYYY INITIALS".
- Right: "UW Medicine | Fred Hutch".
- Full-width decorative gradient bar (6.5 in x 0.12 in) under the text, no outline.

## Callout boxes
One-row, two-column table. Icon cell about 0.4 in, text cell about 6 in, 0.5 pt black borders, no fill, text vertically centered. All box text uses Tip Text. Four types, each with its own icon:
- Efficiency tip (info "i"): a time-saving trick.
- Important note (exclamation "!"): a key step or troubleshooting advice.
- eLearning reference (play icon): "Watch the [lesson] eLearning lesson to learn more about [topic]."
- Page or alternate-guide reference (pointing hand): "Refer to [p. ##/section] for more information on [topic]." or "Refer to the [alternate guide] ..." with a meaningful hyperlink. Page references are fields in Epic-released guides; enter them by hand otherwise.

Boxes can sit inside numbered step lists. Steps use a numbered list, 12 pt.

## Writing conventions the template states
- A main topic is usually one workflow with its steps. If a guide has many workflows, main topics only group them and the steps live in subtopics.
- Link to alternate guides with meaningful link text, not "click here".

## Open items
- The template does not state a body font for table text other than callouts.
- The version line has a hard-coded date and "INITIALS" placeholder; the process for updating it is not in the template.
