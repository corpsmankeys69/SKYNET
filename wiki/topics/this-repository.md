# This Repository

This repo is a live instance of the [[LLM Wiki Pattern]], set up on
2026-08-25 as the owner's personal second brain.

- Schema: `CLAUDE.md` at the repo root — read it before doing anything here.
- Raw sources live in `sources/`, one immutable dated file per source.
- The wiki lives in `wiki/topics/`, one page per concept/entity.
- `wiki/index.md` is the map of content; `wiki/log.md` is the append-only
  history of every ingest/lint/edit.

The first source ever ingested into this wiki was the pattern's own
origin document — see [[LLM Wiki Pattern]] and
`sources/2026-08-25-llm-wiki-pattern.md`.
